# LangChain RAG Chatbot

## Overview

This repository contains experiments and mini projects using LangChain, RAG (Retrieval-Augmented Generation), embeddings, and chatbot development.

## Features

* Document loading (PDF / Text)
* Text splitting
* Embedding generation
* FAISS vector database
* RAG pipeline
* Chatbot responses

## Project Files

* chatbot.py → Chatbot implementation
* rag_base_1.py → Basic RAG pipeline
* rag_base_2.py → Advanced RAG pipeline
* pdf_loaders.py → PDF loading logic
* document_converter.py → Document processing
* Textspliters.py → Text splitting

## Tech Stack

* Python
* LangChain
* FAISS
* Embeddings
* RAG

## Purpose

This repository is part of my AI engineering learning journey and experiments with LangChain.
